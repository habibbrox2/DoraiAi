7. **Legacy plaintext settings never cleared** → **FIXED.** `migrateFromLegacyIfNeeded` rewritten to verify-then-clear: per-key copy incl. previously-missed secrets (`encryption_key`, `email_accounts`, `splinterlands_account`, flat + per-account posting keys discovered by parsing account JSON), then per-key removal from the plaintext store after the encrypted destination is verified to hold every migrated value (destination wins on conflict), once-only via `KEY_MIGRATION_COMPLETE`; never a wholesale `clear()`. `SettingsLegacyMigrationTest` (5 tests) covers copy, verify, per-key removal, idempotence, account discovery, and null-legacy; the `ModelCatalogTest` sits at `commonTest`.
8. **`play-store.yml` arbitrary ref** → **FIXED (implementation), UNVERIFIED at runtime.** Strict `^vX.Y.Z$` validation + tag-exists check + `merge-base --is-ancestor origin/main` before build; secrets via `env:` (never inline); `set -euo pipefail`; Play service-account key validated as JSON after decode; `if: always()` cleanup of `/tmp/keystore.jks` and `fastlane/play-store-key.json`. Note: `keytool -storepass` argv limitation documented as accepted (masked + ephemeral runner + immediate deletion). Actual workflow execution on a real runner was **not** performed — behavior is code-reviewed, not CI-verified.
9. **`FetchUrlTool` DNS-resolution SSRF hole** → **FIXED (defense-in-depth).** New `NetworkAddressGuard` deny-list (loopback, RFC1918, link-local, ULA, multicast, unspecified, CGNAT, benchmarking, reserved, 192.0.0.0/24, metadata hostnames, IPv4-mapped IPv6, NAT64 incl. local-use `64:ff9b:1::/48`) used for literal hosts *and* resolved IPs (Android/Desktop via `resolveHostAddresses`, per-redirect-hop in the existing manual redirect loop); credentialed URLs (`user:pass@`) rejected; `metadata.google.internal` / `metadata.amazonaws.com` / `metadata.goog` denied; unknown forms fail closed. iOS/Web (no DNS API) skip the resolved-IP check — documented limitation; literal checks apply there. DNS-rebinding TOCTOU residual documented in KDoc. Tests: `SsrfAddressGuardTest` (8 ranges incl. NAT64/mapped-v4), `FetchUrlHostTest` (metadata hosts, `isIpLiteralHost`), `DnsResolvedHostGuardTest` (desktop: `localhost` resolves to blocked addresses), all in `desktopTest`.
10. **Free-tier bundle vs runtime mismatch** (17 vs 15) → **FIXED.** Runtime was already 17 ids; the bundle now lists all 17; `log.md` records the alignment; `FreeTierModelsTest` pins the count.
11. **`Service.Free.chatUrl` (kai9000) dead config** → **VERIFIED_NOT_REPRODUCIBLE.** `Requests.kt` resolves the Free service's endpoint with `service.chatUrl` for chat-completions calls (`resolveUrl(service, credentials, service.chatUrl)`), and tests/comments reference the proxy. ### Low

Behavior itself unchanged (non-release CI tasks must not be blocked by missing signing secrets) — documented in CHANGELOG.
