    DORAI AI — Logo Asset Usage Map

    Every asset in the Hexa Core pack — now version-controlled at docs/branding/dorai/assets/hexacore/ — and where (if anywhere) it is consumed in this repository. Canonical copy of the pack lives at docs/branding/dorai/assets/hexacore/; the tables below use paths relative to that directory.

    Legend: used = copied verbatim into an active resource path · derived = converted to a required format/size · unused = kept in the pack for future use, nothing in the app or site consumes it.

    Regenerating

    python tools/import_hexacore_assets.py          # rewrite every derived asset
python tools/import_hexacore_assets.py --check  # verify the source pack only

    The source of truth is the version-controlled pack directory docs/branding/dorai/assets/hexacore/. The importer checks 18 sentinel files, confirms the D-mark path data, and refuses to run if the source looks tampered with. It never touches source XML in composeApp/androidApp, because those carry the adaptive-icon safe-zone group.

    The five legacy tools/{generate,sync}_dorai_*.py scripts are retired behind a hard guard: they exit non-zero unless DORAI_ALLOW_LEGACY_BRAND_GENERATORS=1 is set, because they would overwrite the approved assets with the previous mark.
