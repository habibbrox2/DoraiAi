    6. Remaining risks

    1. Five legacy generators are now hard-retired (not deleted). tools/generate_dorai_{aurora,brand,neo_cyber}_assets.py and tools/sync_dorai_{aurora,brand}_assets.py regenerated the pre-Hexa-Core mark; sync_dorai_aurora_assets.py and generate_dorai_brand_assets.py wrote it straight into logo.xml, ic_launcher_foreground.xml, composeApp/icon.*, the iOS icon, site images and the fastlane store icon. Each now exits non-zero with a pointer to the new importer unless DORAI_ALLOW_LEGACY_BRAND_GENERATORS=1 is set. Residual risk: the override still permits a regression, and the scripts themselves remain readable history.
    2. In-app mark is flat, launcher is gradient. Compose Multiplatform documents XML vectors as Android format “except no external resource references”; aapt:attr gradient behaviour inside multiplatform resources is undocumented, so logo.xml uses two solid palette colours instead of risking a parse failure or a black glyph on Desktop/Wasm/iOS. Android launcher and monochrome keep the pack’s true gradient. Flattening the launcher to match was considered and rejected: the pack is the source of truth and the launcher is the most brand-visible surface. Visual difference is confined to the small in-app glyph.
    3. No API-level constraint on the launcher gradient. gradle/libs.versions.toml sets android-minSdk = "26", so the aapt:attr gradient in the adaptive-icon foreground renders on every supported device. An earlier revision of this report claimed an API 24 floor; that was incorrect for this project (minSdk 26) and minSdk was not changed.
    4. iOS icon catalog has a single universal/ios 1024² slot. The pack ships 1024² only; if iPad/Mac slots are added later, matching sizes must be exported from the pack.
    5. docs/branding/dorai/assets/ still contains the superseded Nexus Orbit direction (with hexacore/ nested inside it, as the brief specified). Nothing in the app or site references it, but the directory layout is now slightly confusing.
    6. Stale build/ output still holds pre-migration copies of logo.xml / ic_launcher_foreground.xml until the next full build; these are gitignored and regenerate.

    8. Refinement after adoption (v2 squircle)

    After the pack was integrated and committed, a refinement was requested and applied. A four-variant render comparison (current / balanced core / squircle / chevron) was made with headless Chrome at 512 px, and the squircle variant was selected.

    What changed in the geometry:

    Property v1 (imported pack) v2 (now)
    Straight-edge stroke 76 / 76 / 80 80 uniform
    Bowl / counter radii 124 / 48 (not concentric) 196 / 116, concentric at x=244
    Core 100 wide, offset right, r=19 94 wide, optically centred, r=22
    Outer left corners R=24 R=34
    Bounding box x 84–438, y 56–456 (354 × 400) x 84–440, y 60–452 (356 × 392)
    Safe-zone fit (scale 0.76) 296 / 312.9 units 297.9 / 312.9 units

    Regenerated from the new numbers: 8 pack SVGs, both wordmarks, 65 theme PNGs, 9 transparent-symbol PNGs, 4 favicon PNGs, favicon.ico, plus every derived asset (iOS icon and launch PDF, desktop png/ico/icns/pdf, site and Wasm icons, touch icons, Play listing icon). Android adaptive foreground now uses android:scaleX/Y="0.76" with pivot (262, 256); the shared logo.xml carries the same paths with solid #25E2F5 / #377CFF fills. MARK_SIGNATURE in the importer is now M118 60 H244.

    Motion assets

    site/img/logo_animation.svg was named for animation but shipped as a static byte copy of the pack symbol. It is now a real animation, authored only from pack parts (mark path, core path, pack gradient):

    Beat Timing What moves
    Reveal 0–0.9 s, ease-out A mask sweeps the mark in from its left edge
    Core landing 0.82–1.34 s, cubic-bezier(.34,1.56,.64,1) The forward core pops from 42 % to 100 % with a small overshoot
    Halo 0.8–1.95 s A cyan radial glow blooms and fades behind the core
    Breathe 1.6 s onward, 4.2 s loop The core scales 1.00 → 1.045 and back

    prefers-reduced-motion: reduce disables every animation and leaves the static mark. Canonical source: docs/branding/dorai/assets/motion/logo-animation.svg (copied to site/img/logo_animation.svg); assets/motion/logo-animation.gif is a 400², 64-frame, 18 fps raster built from the same layers for surfaces that cannot animate SVG. Verified in headless Chrome: 14.5 % canvas coverage at 150 ms versus 33.7 % settled, and the settled frame matches the static pack symbol at IoU 0.9977.

Authoring it again from the new mark also removes the last old-logo artwork from the deployed site.

    The card keeps every string the site already publishes — the lockup, “Intelligence, in every direction.”, “Your AI. Your World.”, the two-line description, the 01–05 feature chips, the LOCAL / CLOUD / HYBRID pill and “ONE ASSISTANT.     Verified after rendering at 1200×630: the mark and the outer ring stay inside the canvas (right edge 1198), every chip label fits its box with at least 8 px of padding, the navy field has no white pixels, and both output files are 24-bit RGB and byte-identical.

    Animated banner

    assets/motion/banner-animation.svg is a 1200×630 staged animation of the social card: the field and rings fade up, the mark sweeps in, the lockup and rule follow, then both taglines, the description, the five chips (80 ms apart), the platform pill and the footer rise into place while the core pops and starts breathing. prefers-reduced-motion shows the finished composition immediately.

    Beat Start Beat Start
    Field + rings 0.00 s Core pop + halo 1.00 s
    Mark reveal 0.25 s Chips (staggered) 1.50 s
    Lockup 0.50 s Pill 1.95 s
    Rule 0.85 s Footer 2.08 s
    Taglines 1.00 / 1.12 s Loop length 3.20 s

    The settled frame was compared against the static social card: mean channel difference 0.94, with the remaining delta coming from the breathing core and halo. tools/render_banner_animation.py rebuilds the WebP from per-element layers; the motion README records why frame-stepping with --virtual-time-budget does not work (Chrome's animation clock lags the budget by an inconsistent 0.3–0.8 s and occasionally captures a blank page) and why WebP replaced GIF for the banner.

    Known gap: nothing links the banner into the site yet, so its only consumers today are people who open the files directly.

    Additional motion assets

    Three more animations complete the set, all built from pack parts and all guarded by prefers-reduced-motion:

    Asset Size Behaviour
    loader-animation.svg 128² Seamless 1.8 s loop — the core breathes while two rings expand outward and fade
    wordmark-animation.svg 920×240 Mark settles, DORAI and AI rise, underline draws, then holds
    splash-animation.svg 512² One-shot app splash: tile fade, mark draw, core landing with halo, then settle

    The splash settles to an exact match with the static icon (svg/app-icon-dark.svg, mask IoU 1.0000), so a launch screen ends on precisely the shipped artwork. Two defects were found and fixed while building them: an animated group can lose its placement because a CSS transform overrides the SVG transform attribute (this bit the wordmark mark), and the pack wordmark's #08132B DORAI is invisible on dark surfaces, so the animated lockup uses #F5F8FC.
