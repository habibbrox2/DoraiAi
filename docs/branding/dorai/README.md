# DORAI AI Brand Identity

The approved brand direction is **AURORA**: a premium geometric D mark with a forward/play cue, Neon Cyan → Electric Blue → Violet gradient, and the tagline **Your AI. Your World.**

The final master assets and dark/light variants are maintained in `aurora/`. The app uses the same transparent mark across themes, while surface, text, and accent roles adapt to System / Light / Dark mode. The website follows `prefers-color-scheme`.

See `aurora/README.md` for the complete palette, usage rules, generators, and exported assets.
