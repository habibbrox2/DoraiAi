# DORAI AI — AURORA Brand Identity (Final)

A premium, modern identity built around a clear geometric **D** with a forward/play cue. The signature gradient runs from Neon Cyan through Electric Blue to Violet.

## Brand system
- Primary mark: geometric D / forward-play symbol.
- Primary palette: `#25E2F5`, `#377CFF`, `#6F5BFF`.
- Dark surfaces: `#050A1C`, `#08132B`, `#0D1C38`.
- Light surfaces: `#F5F9FF`, `#FFFFFF`, with deep navy typography.
- Tagline: **Your AI. Your World.**
- Campaign line: **Intelligence, in every direction.**

## Theme behavior
- Dark mode: obsidian/navy surfaces, ice-white typography, cyan-blue glow used sparingly.
- Light mode: white/ice surfaces, deep navy text, high-contrast blue links and the same gradient mark.
- The app follows its existing System / Light / Dark setting. The public site follows the operating-system color preference.
- The D symbol is transparent in UI contexts, so it remains legible on either surface. App icons retain the dark navy tile for platform launcher consistency.
