# DORAI AI — Project rules

Read and follow root `AGENTS.md` as the canonical policy. Read relevant `agents/` guides and `skills/*/SKILL.md`. Parallel tasks require a dedicated Git worktree and path reservations via `scripts/agent-lock.ps1`; see `agents/task-protocol.md` and `agents/file-ownership.md`. Stay within allowed paths, preserve other agents' work, and never weaken security or change dependencies without approval. Use `scripts/validate-changes.ps1` for tiered validation. No commit, push, PR, merge, release, or deploy without explicit authorization.
